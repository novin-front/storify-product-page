# صفحهٔ معرفی استوریفای

صفحهٔ مستقل فارسی و RTL؛ بدون endpoint خصوصی، فرم پرداخت یا جمع‌آوری اطلاعات بازدیدکننده.

```sh
python3 -m http.server 8875 --bind 127.0.0.1 --directory marketing
```

پیش‌نمایش: http://127.0.0.1:8875/ . برای میزبانی عمومی محتویات این پوشه را روی میزبانی استاتیک قرار دهید. مخزن انتشار مستقل: https://github.com/novin-front/storify-product-page ؛ نشانی GitHub Pages: https://novin-front.github.io/storify-product-page/ . تنظیم انتشار: شاخهٔ main و پوشهٔ ریشه.

دمو خرید را فقط در حافظهٔ صفحه شبیه‌سازی می‌کند. قیمت و تصویر کیف نمایشی‌اند؛ عکس editorial-bag.jpg برای این صفحه با هوش مصنوعی تولید شده است. تصاویر studio/analytics/settings اسکرین‌شات واقعی محیط آزمایش افزونه‌اند. فونت وزیرمتن طبق مجوز موجود در THIRD-PARTY-NOTICES پروژه استفاده می‌شود.

آزمون: `npm run test:marketing` با Playwright و Chrome. امکانات جاری و نقشهٔ راه جدا هستند؛ لینک خرید و قیمت افزونه پس از تعیین شرایط انتشار اضافه می‌شود.

بازطراحی 0.7: هشت نمونهٔ حلقه، کارگاه زنده، کارت‌ها، حرکت، واکنش/CTA، سئو، سرعت و امنیت. `assets/story-atlas.jpg` تصویر نمایشی اصیل تولیدشده با هوش مصنوعی است. آیکون‌های حجمی از مجموعهٔ دارای مجوز پروژه‌اند. `python3 scripts/sync-showcase.py` CSS پیش‌نمایش و موتور حرکت را با افزونه همگام می‌کند. هیچ امتیاز عملکرد یا رتبهٔ جست‌وجوی فرضی درج نشده است.
